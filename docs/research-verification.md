# 리서치 검증 메모 (2026-08-12)

원 리서치가 "라이브 웹 검색 불가" 상태로 작성되어 남긴 빈칸을 실제 검색으로 채운 문서.
원 보고서의 `[추정]`/`[가설]` 중 확정된 것, 정정된 것, 새로 발견된 것을 구분한다.

## 0. 가장 큰 정정: "빈 공간"이 아니다 — 이미 만들어졌고, 성장하지 못했다

원 보고서는 "조건 결합 필터 + 정책/혼잡 정보는 기존 지도에 구조화되지 않은 빈 공간"이라고 봤다.
**국내에 동일 컨셉 서비스가 이미 존재한다.**

### 카공지도 (카공지도.com + iOS 앱)
- 개발자: Seung ju lee / 무료 / iPhone 전용 (iOS 15.6+, 9.9MB)
- 출시 2024-06-07, 최종 업데이트 2024-06-19 (v1.1.4)
- 컨셉: "실제 카공러 후기 100만개+ 기반 AI 분석"
- 제공 필터: 콘센트, 분위기, 자리 여유, 와이파이, 24시간 운영, 주차, 단체석,
  편안한 좌석, 깨끗한 화장실, 음료 가성비, **시간 제한 여부**
- 리뷰 적은 카페는 "카공 점수" AI 추정, 큐레이터 테마 컬렉션, UGC 등록/리뷰
- **App Store 평점 3.7 / 리뷰 3개**

→ 원 보고서가 차별점으로 제시한 것(결합 필터 + 정책/시간제한 구조화 + AI 리뷰 분석)이
   **이미 전부 구현되어 있다.** 그런데 출시 후 12일 만에 업데이트가 멈췄고 리뷰가 3개다.

**따라서 질문이 바뀐다: "만들 수 있는가"가 아니라 "왜 아무도 안 쓰는가".**
이건 원 보고서의 "vitamin이지 painkiller가 아닐 위험" 가설에 대한 국내 자연실험 결과에 가깝다.

### 인접 사례
- MOCA — 카공족 카페 공부 기록 앱 (iOS)
- cagongmap.com — "공부·작업하기 좋은 카페 지도" 타이틀로 이미 응답함 (소유 주체 확인 필요.
  본 프로젝트 디렉터리명과 동일하므로 본인 소유일 가능성)

## 1. 확정된 수치 (원 보고서 체크리스트 대응)

| 항목 | 확정치 | 출처 시점 |
|---|---|---|

### 이 수치들이 말하는 것
1. **원격근무 세그먼트는 얇다 (4.4%).** 원 보고서의 "한국은 원격근무 정착률 낮음" 추정이 확인됐다.
   지불의사 있는 원격근무자 층을 수익 기반으로 잡는 설계는 모수가 작다.
2. **카페 시장은 이미 감소 전환.** 공급 과잉·경쟁 심화 국면 → 업주가 회전율에 더 민감해진다
   = 카공족 적대성이 완화될 이유가 없다.
3. **가장 강력한 신규 반증: 돈 내는 카공 수요는 이미 스터디카페가 흡수했다.**
   10년 62배 성장, 6,944개, 2조원. "집중 환경에 돈 낼 사람"은 카페가 아니라 스터디카페로 갔다.
   카페에 남은 층은 정의상 **무료를 원하는 층**이다. 원 보고서의 지불의사 미스매치가
   숫자로 확인된 셈.

## 2. 카공족 공급측 적대성 — [추정] → [사실] 확정

언론 보도로 확인된 카페들의 실제 대응:
- 콘센트 막기 / 아예 제거, **와이파이 차단**
- **콘센트 유료화**: 30분 990원 / 1시간 1,980원 / 2시간 3,960원 이용권 결제
- 서울 종로구 개인 카페: **카페 내 노트북·태블릿 사용 자체 금지**
- 일정 크기 이상 전자기기 반입 금지, 이용시간 제한, 추가 주문 요구
- 냉난방 조절, 수능금지곡 반복 재생 등 간접 압박
- "카페 빌런 카공족, 법으로 못막나" 류의 기사가 2023~2025 계속 생산됨

→ **업주 제휴 / 유료 등재 수익모델의 근본 리스크가 확정됐다.**
   "노트북 환영 카페"로 홍보되는 것이 업주에게 이득이라는 전제가 다수 카페에 대해 성립하지 않는다.
   원 보고서의 완화안("한산한 시간대 유휴좌석 채우기" 프레이밍)은 여전히 유효한 유일한 각도.

## 3. API 약관·비용 — 실질 제약 확인 (원 보고서보다 심각)

### 카카오맵
- **"로컬 API 응답 결과 데이터는 별도 저장하여 사용할 수 없음"** — FAQ에 명시
- 가이드에 안내된 방법 외 리소스 직접 접근 불허
- REST API 정보수집 시 최대 45페이지 × 15개 제한
- 카카오 데브톡에 **"정책 및 약관 위반에 따른 API 차단 예정 조치"** 공지·사례가 반복 게시됨
  (즉 집행이 실제로 이루어지고 있음)

### 네이버 클라우드 플랫폼 Maps API
- **신규 이용 신청 차단: 2025-05-22 / 무료 혜택 종료: 2025-07-01**
- 기존 이용자는 계속 사용 가능하나 **유료 과금 전환**
- 대표계정 1개 한정으로 API별 월 3,000건~1억건 무료였던 구조가 종료

→ **원 보고서에 없던 결론 2개:**
   1. 크롤링 기반 데이터 확보는 약관 위반이며 차단이 실제 집행된다. 자체 UGC 외 선택지 없음.
   2. **지도 표시 자체가 이제 비용 항목이다.** 무료 지도 위에 얹는 사이드프로젝트 전제가 깨졌다.
      MVP 단계에서도 단위경제에 바닥 비용이 생긴다.

## 4. 네이버 리뷰 키워드 — 정정 및 잔여 과제

- 네이버 플레이스는 **2021-10-27부터 별점 폐지, 키워드 리뷰 도입**.
  업종별 10~20개 키워드 중 **최대 5개 선택**. 음식점·카페·술집 등 10개 업종 적용.
- 최근 약 5년 만에 **5점 만점 별점 리뷰 부활** (키워드와 병행)
- 즉 "노트북하기 좋아요"류는 자유 텍스트가 아니라 **사용자가 고르는 정형 키워드**다.
  원 보고서가 "리뷰 텍스트에 산재, 구조화 안 됨"이라 본 것보다 네이버 쪽이 더 정형화되어 있다.

**잔여 과제(미확인):** 이 키워드를 축으로 한 *지도 위 필터링 UI*의 존재 여부는 검색으로 확정 못 함.
→ 네이버 지도 앱에서 직접 카페 검색 후 필터 메뉴를 캡처해 확정할 것. 이게 차별점 유무를 가르는 단일 최대 변수.

## 5. 해외 선행 서비스 — 정정

| 서비스 | 원 보고서 | 검증 결과 |
|---|---|---|
| Work Hard Anywhere | 소멸/중단 추정 | **확인.** AlternativeTo에 "Discontinued" 표기, 웹사이트는 쇼핑몰로 대체됨. 전성기 57개국 2,500개 카페 |
| Workfrom | 쇠퇴 | **부분 정정.** workfrom.co 여전히 운영 주장(1,250+ 도시), workfrom.com(가상 코워킹)·cafe.workfrom.co로 분화. 단 접속 시도는 연결 거부(불안정). "쇠퇴 확정"은 과장 |
| Cafe Nomad (대만) | 장수, 열성 커뮤니티 의존 | **확인 + 규모 확보.** 타이베이 1,662곳 / 타이난 252곳 / 핑둥 55곳. 무료 와이파이 569건, 콘센트 441건, "노트북 작업 적합" 42건 태깅. 커뮤니티 개발 앱 생태계(/apps)까지 존재 |

**Cafe Nomad이 유일하게 성공한 동일 컨셉 서비스다.** 특징:
- 창업자가 본인이 카페에서 일하는 개발자 — 본인 방문 데이터로 시드 구축 후 개방
- 평가 항목을 먼저 정의하고 커뮤니티에 개방 (스키마 우선)
- 오픈 데이터 + 서드파티 앱 생태계 허용 → 유지비를 커뮤니티에 분산
→ 벤치마크는 Workfrom이 아니라 **Cafe Nomad**로 잡아야 한다.

## 6. 로컬 시드 데이터 확인

`data/cafes.json` — 송리단길·석촌호수 인근 카페 시드가 이미 존재.
스키마: `outlet(many/some) / wifi / noise(quiet) / work_fit(good) / open_time / close_time /
is_24h / iced_americano_price / naver_place_url / tags[]`

→ 원 보고서의 "1개 생활권 50~100곳 깊고 좁게" 권고와 이미 같은 방향. Cafe Nomad의 시작 방식과도 일치.
   다만 현재 규모는 수 개 수준이며, `work_fit`·`noise`가 어떻게 판정됐는지(직접 방문 / 리뷰 추정)가
   데이터 신뢰도의 핵심. 크롤링으로 채웠다면 3장의 약관 리스크에 직결된다.

## 7. 수정된 종합 판단

원 보고서의 결론(데이터 신선도·콜드스타트·수익모델 삼중고, vitamin 위험)은 **유지**된다.
단, 근거의 무게중심이 이동한다.

### 강화된 것
- 카공족 수요와 업주 적대성 모두 [사실]로 확정 → 이해충돌은 가설이 아니라 전제다
- 지불의사 미스매치가 스터디카페 6,944개/2조원이라는 숫자로 확인됨

### 새로 추가된 반증 (원 보고서에 없던 것)
1. **동일 컨셉 국내 서비스가 이미 존재하고 성장하지 못했다** (카공지도, 2024)
2. **지불의사 있는 수요는 스터디카페가 이미 흡수했다**
3. **지도 API 무료 시대 종료** — 사이드프로젝트 단계에서도 비용이 발생한다
4. 커피전문점 수가 감소 전환 — 업주의 회전율 민감도가 높아지는 방향

### 약화된 것
- "결합 필터 = 빈 공간" 가설. 빈 공간이 아니라 **시도됐고 비어 보이는 공간**이다.

## 8. 수정된 검증 우선순위

기존 Top 3를 아래로 대체한다.

1. **카공지도 부검 (최우선, 비용 거의 0)**
   왜 성장하지 못했는가를 역추적. App Store 리뷰 3건 전문, 커뮤니티 언급, 개발자 접촉/인터뷰.
   "수요가 없었나 / 유통에 실패했나 / 데이터 유지에 지쳤나" 중 어느 것인지가
   이 프로젝트 진행 여부를 사실상 결정한다. **가장 싸고 정보가치가 가장 높다.**

2. **네이버 지도 필터 UI 실측 (반나절)**
   카페 검색 → 필터 메뉴 캡처. 키워드 기반 지도 필터가 이미 있으면 차별점의 절반이 사라진다.
   있으면 "혼잡도·시간제한 검증"만 남고, 없으면 결합 필터가 여전히 유효.

3. **송리단길 시드로 갱신 공수 실측 (1~2주)**
   기존 `cafes.json`을 50~100곳으로 확장하고, 4주 뒤 재검증해 **정보가 몇 %나 낡는지** 측정.
   카공지도가 멈춘 지점이 여기일 가능성이 높으므로, 이 숫자가 사업 가능성의 상한을 정한다.

4. (조건부) 업주 인터뷰 20곳 — 단, 3장 결과상 "한가한 시간대 송객" 프레이밍으로만 접근할 것.
