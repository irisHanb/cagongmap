# Visual Analysis — https://cagongmap-nu.vercel.app/

## 결론부터: 지도, 프로덕션에서 정상 렌더됨

`vercel.app` 도메인이 Kakao 콘솔 플랫폼 도메인에 등록돼 있는 것으로 확인돼요.
Kakao map fallback 안내 문구가 아니라 실제 지도 타일과 마커 7개(스냅샷 기준, dock 뒤에
가려진 2개 포함 9개)가 뜨고, 우측 하단 "Kakao 맵으로 이동" attribution 링크도
`map.kakao.com`으로 정상 연결돼 있어요. 콘솔 도메인 등록 문제는 없다고 봐도 됩니다.

콘솔 로그는 에러 0건, 경고 1건(`Multiple GoTrueClient instances detected` — Supabase
클라이언트 인스턴스 중복 경고, 화면에는 영향 없음)이었어요.

## 스크린샷

- Desktop (1440x900): `desktop.png`
- Mobile (390x844): `mobile.png`

## Desktop (1440x900)

- Above-the-fold에 "카공맵" H1, 부제("오래 앉아 작업하기 좋은 카페 9곳"), "카카오 로그인"
  CTA, "카페 제보하기" 버튼이 모두 스크롤 없이 보여요. dock 카드가 좌상단 358px 폭으로
  깔끔하게 떠 있고, 그 뒤로 송파·잠실 권역 지도와 원형 카페 마커들이 겹침 없이 잘
  드러나요.
- 지도가 `100dvh` 풀스크린이고 dock이 그 위에 얇게 얹힌 구조라 레이아웃 시프트나
  overlapping 요소는 안 보였어요. 마커 원형 사진 크롭도 정상 렌더돼요.
- 화면 왼쪽 끝에 마커 하나가 절반 잘려 보이는데, 이건 초기 지도 중심(송리단길)과
  뷰포트 폭에 따른 자연스러운 결과라 레이아웃 버그는 아니에요.

## Mobile (390x844)

- dock 카드가 top 16px~bottom 252px, 즉 뷰포트 높이의 약 28%를 차지해요. H1·부제·
  CTA 두 개까지는 fold 안에 다 들어오지만, **지도 자체는 dock 아래로 밀려서 카드 바로
  아래 좁은 띠만 보여요.** 마커도 거의 다 dock에 가려지고 하나만 겨우 상단 경계에
  걸쳐 보입니다.
- 공유 링크로 처음 들어온 방문자 관점에서 보면, 이 서비스의 핵심 가치("지도에서
  카페를 찾는다")를 mobile 첫 화면에서 바로 느끼기 어려워요. 지도가 보이는 영역이
  좁아서 "카페 위치가 어디쯤인지" 감이 잘 안 옵니다. 데스크톱에서는 이 문제가 없어요
  (dock이 지도 대비 훨씬 작은 비율이라).
- 가로 스크롤은 없어요 (`scrollWidth === innerWidth === 390`).
- 폰트: body/paragraph 16px, H1 28px로 가독성 기준(16px+)을 충족해요. 확대 없이도
  읽기 편한 크기예요.

### Tap target 측정치

| 요소 | 크기 | 판정 |
|---|---|---|
| 카카오 로그인 버튼 | 318 x 48px | 48px 최소 기준 충족 |
| 카페 제보하기 버튼 | 318 x 40px | **48px 기준 미달** (8px 부족) |
| 카페 마커(원형) | 46 x 46px | **48px 기준에 살짝 미달** (2px 부족) |

카페 제보하기 버튼과 마커는 손가락 터치 기준(WCAG 2.5.5, 일반적으로 48x48px 권장)에
살짝 못 미쳐요. 폭 318px에 여유가 있으니 제보 버튼은 padding을 늘려 44~48px로
맞추는 걸 검토할 만해요. 마커는 2px 차이라 실사용에 큰 지장은 없을 것으로 보여요.

## 첫 방문자(공유 링크) 관점 요약

1. **지도가 뜬다는 것 자체는 확인됐어요** — vercel.app 배포에서 fallback 문구 없이
   실제 지도가 보입니다. 배포 도메인 등록 문제는 해소된 상태예요.
2. **데스크톱 above-the-fold는 좋아요** — 브랜드, 가치 제안, CTA, 지도가 한 화면에
   다 들어오고 겹침도 없어요.
3. **모바일에서는 지도 비중이 작아요** — dock이 화면의 28%를 차지해 지도가 좁은
   띠로 보이고 마커도 대부분 가려져요. 카공맵처럼 "지도가 핵심"인 서비스에서 모바일
   fold의 대부분을 텍스트 카드가 차지하는 건 첫인상에서 아쉬운 지점이에요. dock을
   접을 수 있게 하거나(collapsed 상태로 시작) 카드 높이를 줄이는 방향을 고려할 만해요.
4. **터치 타겟 두 곳이 48px 기준에 살짝 못 미쳐요** — "카페 제보하기" 버튼(40px)과
   마커(46px). 특히 제보 버튼은 8px 차이로 여유 있게 고칠 수 있는 부분이에요.
5. 가로 스크롤, 텍스트 잘림, 레이아웃 깨짐은 desktop/mobile 어느 쪽에서도 발견되지
   않았어요.
