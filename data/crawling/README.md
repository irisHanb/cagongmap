# 후보 목록 — 데이터가 아니다

여기 있는 파일은 **"가 볼 만한 카페" 후보 URL 목록**이다. 앱이 읽지 않고,
`places` 테이블로 그대로 넘어가지도 않는다.

파일 이름은 `{YYYYMM}-{장소}.md`이고, 안에는 상호명과 URL만 적는다.

## 왜 이것이 「크롤링 금지」에 걸리지 않나

「크롤링 금지」(`docs/mvp-decisions.md` 2-1)가 막는 것은 **카카오맵 API 응답을 데이터로
삼는 것**이다. 여기 모으는 것은 API 응답이 아니라 검색으로 찾은 장소 페이지 주소이고,
**`places`의 값은 여전히 사람이 확인해서 손으로 채운다.**

가르는 기준은 하나다 — **그 값이 `places`로 그대로 넘어가는가.**

- ⛔ API 응답의 좌표·주소·사진 URL을 옮겨 담는 것
- ⛔ 자동화로 장소 페이지를 긁어 필드를 추출하는 것
- ✅ 후보 URL과 상호명을 모아 두고, 사람이 확인해서 값을 적는 것

전체 경계표는 `docs/mvp-decisions.md` 2-1절에 있다.
